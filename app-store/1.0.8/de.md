# Poly 1.0.8 — Deutsch (de-DE)

Only What's New changes in 1.0.8. Every other field stays as in `../1.0.7/de.md`.

## What's New *(4000)*
```
Poly 1.0.8 macht die Gratis-Testphase klarer und glättet ein paar Ecken.

• Erinnerung: eine Mitteilung 2 Tage bevor deine Gratis-Testphase endet
• Die Einstellungen zeigen jetzt, wann deine Testphase endet und was sie danach kostet
• Kamerazugriff ausgeschaltet? Poly erklärt jetzt, wie du ihn wieder einschaltest, mit einem Button zu den Einstellungen
• Beim Upgrade auf Lebenslang hilft dir Poly jetzt, dein altes Abo zu kündigen, damit du nie doppelt zahlst
• Preise laden jetzt neu, wenn du beim Öffnen von Poly offline warst
• Eine leichtere Kameraansicht und kleine Verbesserungen
```
